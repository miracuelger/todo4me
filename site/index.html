Today and tasks

A calm list for today

Today shows what is left and what is late, and nothing else competes with it. The quick-add line sets priority, category and date in one go, so a task is one line of typing.

  • Priorities from Critical to Low, due dates with optional time
  • Subtasks, tags and categories
  • Repeat daily, on weekdays or every few weeks
  • Reminders at the due time or before, with snooze

Weekly planner

Drag your week into shape

Move tasks between days, or switch to an hourly grid and plan with time blocks you can move, resize and create. Outlook and Google calendars can appear read-only in the desktop app.

  • Day columns or hourly calendar view
  • Daily plan with a main goal, a top 3 and a reflection
  • Focus mode with a Pomodoro timer

Documents and knowledge

Write like in a word processor. Connect like in a wiki.

Proper documents with headings, tables, images, formulas and code, linked with [[wiki links]]. Backlinks and a graph view show how your notes relate.

  • Version history with word-level compare
  • Find and replace, focus mode, formulas and code
  • Import and export Word and Markdown, save as PDF

Pen and handwriting

Draw in your documents

A pen with pressure, a highlighter, an eraser, a lasso and shapes with optional recognition. Use handwriting canvases with grid and layers, or annotate over text and formulas. It works with mouse, touch and pen, and stays fully offline.

  • Exports to SVG, PNG and PDF
  • Strokes stay editable vector data

Privacy

Your data stays yours

Todo4Me runs offline on your computer. It is open source under the MIT license, so you can check this yourself.

Offline first
Everything works without an internet connection.
No account
Install it and start. No sign-up, no email address.
No cloud, no tracking
Nothing is uploaded and no usage data is collected.
A folder on your computer
Windows: %APPDATA%\Todo4Me, Linux: ~/.config/Todo4Me. Updating, reinstalling and uninstalling do not delete it.
Backups you control
A daily automatic backup of the last 14 days, plus JSON export and import whenever you like.
Honest about the network
The desktop app goes online only to check for updates and, if you set them up, to load subscribed calendars.

Latest version: see the release page

Todo4Me is available for Windows and Linux. On other systems, such as macOS, iOS or Android, use the browser version.

Recommended for your system

Windows

  • Installer (recommended)No admin rights needed. Creates a desktop shortcut and a Start menu entry, and updates itself.
    Download

    Todo4Me-Setup-*.exe

  • PortableRuns without installation, for example from a USB stick. Does not update itself.
    Download

    Todo4Me-*-portable.exe

SmartScreen: the files are not digitally signed. If Windows shows “Windows protected your PC”, choose More info, then Run anyway.

Your data lives in %APPDATA%\Todo4Me. Installed and portable versions share it.

Recommended for your system

Linux

  • Ubuntu, Debian, Mint.deb package, recommended on Ubuntu
    Download
    sudo apt install ./Todo4Me-*-amd64.deb
  • Fedora, RHEL, openSUSE.rpm package
    Download
    sudo dnf install ./Todo4Me-*-x86_64.rpm
  • Any distributionAppImage, updates itself
    Download
    chmod +x Todo4Me-*.AppImage && ./Todo4Me-*.AppImage
  • Any distribution.tar.gz, no installation. Run todo4me from the extracted folder.
    Download
    tar xzf Todo4Me-*-x64.tar.gz

AppImage needs FUSE 2. On Ubuntu 22.04 and newer install it with sudo apt install libfuse2t64 (older: libfuse2), or start the AppImage with --appimage-extract-and-run.

On Ubuntu 23.10 and newer, the deb and rpm packages keep Chromium’s sandbox through an AppArmor profile, which is why they are recommended there.

Your data lives in ~/.config/Todo4Me.

No installation needed?

FAQ

Questions

Is Todo4Me free?
Yes. It is open source under the MIT license, with no ads and no paid tier.
Do I need an account or an internet connection?
No account, and it works offline. The desktop app goes online only to check for updates and, if you set them up, to load subscribed calendars.
Where is my data?
In a folder on your computer: %APPDATA%\Todo4Me on Windows and ~/.config/Todo4Me on Linux. The browser version keeps its data in that browser.
Can I use it on several devices?
Todo4Me has no sync service. You can move your data with JSON export and import.
Which systems are supported?
Windows and Linux (x86_64) as desktop apps. On other systems, such as macOS, iOS or Android, use the browser version.
Why does Windows warn me about the installer?
The files are not digitally signed. Choose More info, then Run anyway.
Does it update itself?
The Windows installer, the AppImage and the deb and rpm packages can update themselves. The portable version and the .tar.gz do not.
